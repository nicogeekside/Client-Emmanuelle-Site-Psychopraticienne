# Liste des images nécessaires

Pour finaliser le site, voici la liste des photos à fournir.
Dans l'idéal, les photos doivent être en haute définition (HD). Je me chargerai de l'optimisation.

## Page d'Accueil
- [x] **Hero Header** (Grande image principale) : Une photo ambiance cabinet ou un portrait de vous en situation d'écoute. Format paysage.
- [x] **Présentation** : Un portrait professionnel souriant (format carré ou portrait).

## Pages "Silos" & Services
- [x] **EMDR** : Une image illustrant l'apaisement ou la thérapie (ex: mains, cabinet zen).
- [x] **EFT** : Une image illustrant le "Tapping" ou la gestion des émotions.
- [x] **Périnatalité** : Une image douce évoquant la maternité ou le soutien.

## Page À Propos
- [x] **Photos du cabinet** : 2 ou 3 photos de votre lieu de consultation pour rassurer les visiteurs (salle d'attente, fauteuil...).

## Autres
- [ ] **Social Image** : Une image par défaut pour le partage sur Facebook/LinkedIn (souvent le logo ou le portrait).
- [ ] **Favicon** : Le logo en petit format (carré).
